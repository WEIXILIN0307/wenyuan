# 首版格式与布局支持矩阵

“支持”限本项目模型表达的子集；不等于所有来源 DOCX 的等价排版。原件保留在用户
所属文档中，可下载核对。文件只解析数据，不执行脚本、宏或对象。

| 功能 | DOCX 导入/导出 | 可能损失/处理 |
|---|---|---|
| 段落和正文 Unicode | 支持 | 控制字符拒绝；不支持任意双向文字布局 |
| Heading1–6 标题 | 支持 | 自定义命名/样式继承部分支持，降级提示 |
| 粗体、斜体 | 支持直接格式 | 样式继承、主题字体可能变化 |
| 字号、RGB 文字颜色 | 支持直接格式 | 主题色、字体替换、背景、下划线等不保真 |
| 左/中/右/两端对齐、段后间距 | 支持 | 预览两端对齐降级左对齐并提示；不含完整禁则 |
| 页宽/页高/统一四边距 | 支持单节子集 | 不等边距采用上边距并提示；多节降级 |
| 单层有序/无序列表 | 支持 | 多级列表导入展平提示；嵌套列表导出拒绝 |
| HTTP/HTTPS/mailto 链接 | 支持 | 内部书签及不安全协议去除并提示 |
| 行内 PNG/JPEG | 支持 | 不抓取 URL，不支持浮动锚定、裁剪或环绕 |
| 简单矩形表格 | 支持 | 表头为完整行，无合并/嵌套/自定义列宽 |
| 合并、嵌套、跨页表格 | 不支持 | 合并/嵌套导入降级并提示；不承诺等价 |
| 页眉页脚/页码/脚注/尾注/批注 | 不支持 | 导入提示，原件供核对；后续阶段再实现 |
| 分栏、修订、字段、浮动对象、公式 | 不支持 | 检出后提示，不等价呈现；不能无损往返 |
| 宏、OLE、嵌入对象、加密包 | 不支持 | 拒绝解析 |
| 字体包、完整 Word/WPS 排版 | 不支持 | 不附带字体或 Office 引擎 |

DOCX 导出后在同一受限进程内重新解析，比较支持范围内的文字、块结构、标记、
列表编号、图片及尺寸、表格、对齐与段距；节点 ID 不属于交换格式，导入后重新生成。
这不是独立 Office 渲染器验收。损失矩阵和人工核对仍必需。

Markdown 支持段落、ATX 标题、粗斜体、链接、单层列表、简单表格及 data PNG/JPEG。
外部图片不抓取，代码块降级正文；HTML 不执行。导出明确提示格式损失并回读核对文字。
复杂表格/列表无法表示时拒绝导出。原生 JSON 保留全部已支持模型，schema_version
未知则拒绝，不自行猜测迁移。

布局为自有 TypeScript 模块：Canvas 实测字体，Intl.Segmenter 分割字素，逐行贪心
换行、固定行距和页边距分页，带节点/UTF-16 位置映射。文字预览与编辑连续视图分开。
整表不能跨页，大图/整表超页可见警告。没有孤行控制、中文标点完整禁则、断词、
双向文字、浮动环绕或 Word 的字体整形/网格等价承诺；表格预览为基础估算。

上传 10MB，请求 12MB，ZIP 最多 512 项、解压合计 40MB、单项 20MB、压缩比限制；
拒绝绝对/父级/反斜线路径和重复项，所有 XML（含未使用部件）禁止 DTD/实体。
解析与导出子进程：512MiB 地址空间、8s CPU、10s 墙钟，同时最多两个转换。
PNG/JPEG：2MB、1200 万像素。默认不抓取任何图片或网页 URL。

模板绑定、提案历史及引用来源元数据属于文渊原生 JSON/数据库能力，不包含在 DOCX/
Markdown 交换文件中。AI 引用界面可回读资料与版本，但不宣称导出包含 Word 脚注或
可自动更新的引文域。系统字体由用户安装，原创预设不是公文法定格式认证。

本轮真实 LibreOffice 7.3 GUI/PDF 检查保留了标题、正文、列表与表格文字；标题字体/
大小、项目符号、表头背景与粗细和浏览器不同。字体未嵌入，标题级别不等于跨软件
完全相同的 CSS 外观；详见 SEED_VALIDATION.md。Word/WPS 未验收。
