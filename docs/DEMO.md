# 隔离演示复现

先按 README 安装与启动；每次演示使用新目录 `WENYUAN_DATA` 和 `create-user` 创建的
专用账号，只上传 `examples/` 或自行编写的合成资料。模型服务必须得到使用授权，
通过服务端 CLI 配置。不要复用生产账号、客户文稿、旧知识库或浏览器个人资料。

建议连续演示 2–3 分钟：

1. 从主导航打开模板库，预览并创建通知，展示原创章节与基础样式，修改标题。
2. 在知识库新建合成资料库，上传合成 TXT，检索“阅读活动”，打开真实片段并添加到当前文稿。
3. 选中同一正文段落，打开 Good AI 选“改写”，说明要求；查看本轮选区、背景与资料。
4. 调用已授权模型，展示待确认建议、差异、限制和真实引用，点击引用核对原文。
5. 确认应用，补充人工编辑；保存后刷新打开，核实仍在。
6. 展示确定性检查的依据，补充简单列表/表格并导出 DOCX；回读与独立 Office 检查。

模型延迟也属于真实录制，不把等待剪成伪造的即时生成。没有授权/无法连接时，
只能使用测试目录中的模拟器并在画面/说明中明确标注“模拟模型”，不能作为真实模型验收。
